# applied-lab 🔬

Themed, **iteratively-built** experiments at the intersection of **security**, **AI/ML**, and **fintech**.

Unlike a one-off snippet repo, each project here *grows*. A scheduled [Claude Code](https://claude.com/claude-code) session works on the current project a little each day — adding a feature, hardening an edge case, writing a test, improving the docs — and commits that increment. When a project reaches a natural stopping point it's marked done and a new one begins on the next theme in the rotation.

This is disclosed automation: commits are co-authored by Claude, and the whole point is to watch small ideas compound into real, runnable tools over time.

## Themes (rotating)

- 🔐 **security** — static analysis toys, crypto demonstrations (educational), auth/protocol simulators, fuzzing harnesses, log-anomaly detectors
- 🤖 **ai/ml** — from-scratch models (no frameworks), tiny autograd, embeddings, tokenizers, search/retrieval, evaluation harnesses
- 💹 **fintech** — order-book simulators, backtesting engines, risk metrics, options pricing, portfolio math, market-data tooling

Everything runs on `python3` (stdlib) or `node`, no installs.
